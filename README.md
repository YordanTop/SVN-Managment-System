# SVN-Managment-System
SVN manager system for checking and maintaing the logs form the SVN servers(stations)

## Prerequisites

№1 Having private sub version control system like VisualSVN

№2 TortoiseSVN

## How to setup this project

After cloning the project or downloading it you should change the connection string form ..\ZPSVN\App.config

![SVNdatabaseconnection](https://github.com/user-attachments/assets/2cb7ffa0-0408-4e35-ad52-f5e5137abffe)

After you set up the connection string, everything it should be good to go.
